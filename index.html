What the app does

The assistant indexes source into searchable code chunks and a symbol graph. Chat combines semantic retrieval with graph neighbors, then validates generated code blocks when language-server support is enabled. The UI also exposes saved schema and domain analyses, code-quality evidence, developer logs, and runtime observations.

Before you begin

  • Have a supported macOS or Ubuntu/Debian host with Docker and enough disk and memory.
  • Keep the source revision you upload identifiable by its project slug and full Git commit SHA.
  • For runtime work, prepare a PHP application that can emit the release telemetry attributes and a matching indexed revision.
