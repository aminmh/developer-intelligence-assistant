User guide

Developer Intelligence Assistant

Index a codebase, ask questions about it, and follow the evidence from source files to runtime requests.

Install Index code Ask questions Code quality Runtime More tools

1. Install and sign in

The local installer supports macOS and Ubuntu/Debian. Check the installation guide for Docker, Ollama, and disk and memory requirements.

git clone https://github.com/aminmh/developer-intelligence-assistant.git
cd developer-intelligence-assistant
bash install.sh
bash install.sh info

Open the app address shown by info and sign in with the generated credentials.

2. Add and index a project

  1. Open Knowledge base → Files and indexing.
  2. Choose a project and upload a ZIP of its source, or connect a branch in Git source and sync it.
  3. Start indexing the revision and wait until it is ready. Select it in the project picker before opening Chat or Code quality.

3. Ask about your code

Open Chat with the indexed revision selected. Start with a specific route, file, or symbol: “Where is the checkout total calculated?” Follow the source references in the answer to verify it.

Assess code quality

  1. Open Code quality and select the project and revision you want to assess.
  2. Run an assessment. Review the categories, then open a finding to check its evidence and suggested next step.
  3. For live HTTP measurements, open Performance. Those runs report separately from the static assessment.

Investigate a runtime request

  1. Follow the PHP telemetry setup guide to connect a running app and its indexed source.
  2. Open Runtime and select the matching project and revision. In Recent sampled requests, choose Errors or Slow to narrow the list.
  3. Open a request and check Database for repeated query shapes. The details depend on what the instrumentation captured.

If no requests appear, generate traffic and check that the deployment reports the same indexed revision.

Find the right tool

API contracts and UI map
Attach an OpenAPI contract in Knowledge base, then compare it with indexed front-end calls and back-end routes.
Database schema
Explore tables and relationships from a saved analysis or import SQL, DBML, or schema JSON.
Domain knowledge
Explore domain concepts and entities found in the indexed project.
Settings and Developer logs
Check model connections in Settings. Use Developer logs to investigate failed requests to the assistant.
