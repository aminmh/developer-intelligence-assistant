Why we must use Developer Assistant

A change can be easy to write and still have consequences that are hard to see. Developer Assistant helps you answer three questions about a specific revision of your project: Where does this behavior come from? Who depends on it? What evidence would make me comfortable shipping a change?

  • Find the code behind a feature. In Index and Chat, ask a question in the language of the product, such as “Where is the invoice total calculated?” Follow the answer’s citations to the source. This gives a new teammate a place to start and gives a reviewer a reference they can check.
  • See who relies on an API. Before renaming a response field, use the Front-End assistant to trace the indexed HTTP calls and compare them with the API contract. A screen that still reads the old field belongs in your change plan, even if it lives far from the endpoint.
  • Decide what still needs testing. The Regression tracker compares a base revision with a candidate. Use the report to choose which affected paths to exercise. If you have runtime telemetry, sampled requests can show what actually ran. A path missing from a sample may still be in use.

How it fits alongside Codex or Claude Code

Codex and Claude Code can investigate a repository, edit files, and run tests. Developer Assistant serves a different part of the job: it brings together source citations, relationships, and revision comparisons that you can inspect and share. Give the coding agent the relevant findings and the behavior you want to preserve. You still review the patch and decide whether the tests cover the risk.

Example: Suppose invoices should display rounded totals, but checkout must keep its current precision. If the cited source shows that both use the same calculation, give your agent a narrower task: “Round the displayed invoice total only. Leave checkout arithmetic unchanged and add a test for each behavior.” After the edit, compare the two revisions and run both tests. The comparison helps you decide where to look; the assertions check what the customer sees and pays.

What the app does

The assistant indexes source into searchable code chunks and a symbol graph. Chat combines semantic retrieval with graph neighbors, then validates generated code blocks when language-server support is enabled. The UI also exposes saved schema and domain analyses, code-quality evidence, developer logs, and runtime observations.

Before you begin

  • Have a supported macOS or Ubuntu/Debian host with Docker and enough disk and memory.
  • Keep the source revision you upload identifiable by its project slug and full Git commit SHA.
  • For runtime work, prepare a PHP application that can emit the release telemetry attributes and a matching indexed revision.
