## Acceptance Criteria

- A remote model that passes the probe selects navigation tools during search, debug, explain, refactor, and knowledge chats.
- A remote model that fails the probe shows tools as unavailable and still answers from retrieval.
- Non-PHP revisions index into Qdrant and Neo4j with Tree-sitter chunks and call edges.
- Symbol lookup reports edge origin; SCIP edges appear for languages whose indexer succeeded.
- Rector and Joern data-flow results appear only as bounded, revision-scoped analyzer evidence.
- The evaluation run shows no RAGAS regression and higher citation accuracy for search and debug questions.
- All new tests pass in `docker compose run python-api pytest`.

- Hazard: scip-php is experimental and needs `vendor/`; unsupported revisions report SCIP coverage as unavailable.
