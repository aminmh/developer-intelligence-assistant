Where data lives

  • Qdrant: vector search for code and knowledge chunks.
  • Neo4j: indexed symbols and graph relationships used for retrieval and definition browsing.
  • MinIO and tusd: source ZIP storage and resumable uploads.
  • SQLite: settings, saved analyses, and local application records.
  • Ollama or configured providers: embeddings and answer generation.

What is sent where

Normal local operation keeps source retrieval and generation in the configured local stack. Remote analyzers are separate: Developer Mode requires worker identity checks and explicit project consent before selected source is transferred. SonarQube adds separate source-upload consent and a host-stored token.

Telemetry privacy boundary

Runtime views do not return raw SQL, bindings, request bodies, or headers. Runtime observations depend on sampling and instrumentation; they do not show complete execution order or complete method coverage.

Release limits

  • Chat answers depend on the indexed revision and retrieved context.
  • Schema and domain graph behavior is bounded by the saved analysis and renderer limits.
  • Performance comparisons need equivalent targets and workload settings.
  • Unknown business-rule results mean the indexed evidence could not verify behavior.
  • Production Mode keeps analyzer execution local; remote Developer Mode is a separate option.
