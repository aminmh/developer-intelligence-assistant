User guide

Install and recover the local stack

Follow the installer in order. It checks dependencies, creates local HTTPS addresses, starts services, and leaves a private report with credentials.

Prerequisites

Use macOS Intel/Apple Silicon or Ubuntu/Debian x86-64/ARM64. Install or prepare Docker 24+, Compose 2.24.4+, Buildx/BuildKit, Python 3.10+, Node 22+, Ollama 0.11+, mkcert 1.4.4+, curl, tar, OpenSSL, Make, SSH, and sudo. Allow at least 40 GiB free disk, four Docker CPUs, and 8 GiB Docker memory; analyzers need 16 GiB.

Install step by step

  1. Download or clone the complete application folder.
  2. Start Docker and complete its desktop permission dialogs.
  3. Start Ollama. On macOS use brew services start ollama; on Linux use sudo systemctl start ollama or ollama serve.
  4. Run bash install.sh from the repository root.
  5. Review the proposed dependencies, hostnames, certificates, and optional services. Type yes only after the displayed plan is correct.
  6. Wait for the model probe and service readiness checks to finish.
  7. Run bash install.sh info and keep the private report. It is stored at .install/services.txt with restricted permissions.
  8. Open the application address from the report and sign in as developer-admin.
Protect the report. It contains passwords and API keys. Do not commit .install or generated environment files.

Recovery commands

just install-check
just install-status
just install-resume
just install
just install-info

Rerun bash install.sh after an interruption. The installer keeps downloads, Docker layers, volumes, models, and checkpoints; it does not prune them during recovery.

Common blockers

Ollama cannot be reached
Start Ollama and make sure the API container can reach the host gateway on port 11434. If required, set OLLAMA_HOST=0.0.0.0:11434 and restart Ollama.
Certificate or browser trust fails
Let mkcert install its local root, then retry in a browser profile that trusts the host certificate store.
Authentication fails after a resume
Check the current persisted account value against the matching environment value. The installer does not reset accounts or delete volumes.
